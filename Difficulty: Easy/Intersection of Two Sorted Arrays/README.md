<strong>Output</strong>: []
<strong>Explanation</strong>: No common elements.</span></pre><pre><span style="font-size: 18px;"><strong>Input</strong>: a[] = [1, 2, 3], b[] = [1, 2, 3]
<strong>Output</strong>: [1, 2, 3]
